Gestão de ASOs
Grupo Energia — Sistema interno
Fluxo automatizado: vencimentos identificados → e-mail ao responsável → sugestão de data → lembrete 1 dia antes → registro pelo admin → resultado → novo ciclo.
Base de dados: Google Sheets (leitura via CSV, escrita via GAS)
Hospedagem: GitHub Pages (estático, gratuito)
Alertas: E-mail automático — 60d, 30d, vencido, 1d antes
Arquitetura: CSV público + GAS endpoint · Sem servidor · Sem custo
